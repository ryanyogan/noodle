Noodle uses a small set of plain words, like Bucket, Commitment and Free to Spend. Each one is explained in the Glossary, so these Docs do not repeat them.

## Where to find it

- Open the [Glossary](/glossary) in the app. You need to be signed in.
- Wherever a word has a small "?" beside it, press it. You get a one-sentence explanation and a link that opens the Glossary at that word, over the page you are on.

## Good to know

- The Glossary is listed A to Z.
- If a word used to be called something else, the Glossary says so.
